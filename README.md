# PennyWise – Flutter Expense Tracker

## Run locally
1. Install Flutter and Android SDK.
2. Open this folder in VS Code or Android Studio.
3. In the terminal, run `flutter pub get`.
4. Connect an Android phone with USB debugging enabled, or start an emulator.
5. Run `flutter run`.

## Features
- Balance, income and expense totals
- Add income and expense transactions
- Category selection
- Filter all / expenses / income
- Swipe left to delete a transaction
- Local persistence using shared_preferences
